# Paid acquisition decision record — PattayaPets

Paid acquisition is **not approved by this document**. It may begin only after the operator records a budget, conversion objective, privacy-approved measurement method, and a current evidence review for each landing page. Organic search quality and reader safety take priority over buying traffic.

## Preconditions

1. Export a dated Search Console query/page baseline and identify a real demand or conversion hypothesis.
2. Confirm the landing page’s canonical URL, index status, reviewed date, sources, structured data, mobile accessibility, and local performance budgets.
3. For regulated travel or emergency content, require the current claim/clinical approval state before any campaign can be activated.
4. For directory pages, require the business integrity gate to report no held record, restricted contact, unsupported availability, or fabricated review signal.
5. Decide and document analytics behavior, retention, consent requirements, and the exact event inventory. Do not assume an analytics product or identifier from historical documentation.
6. Set a hard spend ceiling, named owner, start/end dates, stop rule, and correction/withdrawal route.

## Campaign record template

| Field | Required value |
|---|---|
| Decision owner | TIM |
| Hypothesis | A specific reader need and measurable outcome |
| Evidence date | YYYY-MM-DD |
| Query/audience evidence | Link to dated first-party export or approved research |
| Landing page | Current canonical URL |
| Landing-page approval | Editorial, regulated/clinical if applicable, business integrity if applicable |
| Measurement | Approved event and privacy basis |
| Budget ceiling | Currency, total, and daily maximum |
| Stop rule | Defined before launch |
| Review date | YYYY-MM-DD |
| Final disposition | Continue / revise / stop, with evidence |

## URL parameters

Use only parameters supported by the approved analytics plan. A conventional pattern, if approved, is:

```text
utm_source={platform}&utm_medium=paid&utm_campaign=pattayapets-{approved-slug}&utm_content={creative}
```

The canonical tag must remain parameter-free. Never put personal data, pet health details, travel dates, contact details, or audience-sensitive attributes in a URL.

## Landing-page exclusions

Do not buy traffic to:

- a page with an unresolved canonical, redirect, noindex, source, or freshness state;
- an emergency or regulated page awaiting required review;
- a directory/listing page containing held or unverified operating claims;
- an intent-duplicate page before dated query/page evidence resolves cannibalisation;
- a page that fails accessibility, security, privacy, performance, or build-manifest gates;
- a page whose useful answer is materially thinner than the ad promise.

## Reporting

Evaluate against the predeclared outcome and total spend, not click-through rate alone. Preserve the query, creative, landing URL, dates, spend, conversions, privacy configuration, and any correction. Search-engine index changes, content pruning, and regulated-content revisions are separate decisions and must not be bundled into an advertising experiment.
